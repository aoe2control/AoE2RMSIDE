# Reference numbers

Numbers for reading a quality-check report. The check's limits were
calibrated on reviewed community maps and official maps: maps reviewers
rated well pass at Tiny 1v1 without failures. Use them as orientation, not
as rules; the user's design decides.

## Player base

| Measure | Limit or norm |
| --- | --- |
| Nearest-distance spread per start resource between players | warning above 4 tiles, failure above 12 |
| Wood near base (tree tiles within 20 tiles), difference between players | warning above 25 % |
| Building space within 16 tiles, difference between players | warning above 15 %, failure above 40 % |
| Start objects per player | identical counts; a gap warns, more than 3 objects fails |
| Relics and neutral piles per player | at most 1 apart (community norm) |

The standard start objects and their distance bands are in topic
`player-base`.

## Seeds and settings

| Measure | Typical value |
| --- | --- |
| Seeds per setting for a quality check | 50 |
| Share of seeds on which players notice a problem | 5 to 10 % |
| Seeds on a contact sheet | 6 to 9 |
